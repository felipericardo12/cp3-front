🚀 Sobre o Projeto

A Aura Games é um projeto Front-End criado com foco em visual moderno, identidade gamer e experiência imersiva.

O site apresenta uma interface estilizada com cores neon verdes, efeitos futuristas e elementos interativos, trazendo uma aparência inspirada em setups gamers e no universo cyberpunk.

O projeto foi desenvolvido para praticar:

Estruturação com HTML
Estilização avançada com CSS
Interatividade com JavaScript
Responsividade
Design moderno
